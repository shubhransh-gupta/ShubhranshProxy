ShubhranshProxy

Native macOS HTTP(S) debugging proxy. Capture traffic from this Mac and from iPhone / Android on the same Wi‑Fi — with SSL decryption, Map Local, breakpoints, and more.

Download for macOS View on GitHub

Requires macOS 14+ · Universal build

Mac traffic

Start capture and route macOS apps through 127.0.0.1:8888 automatically.

iPhone / Android

Listen on 0.0.0.0:8888, install the root CA, set Wi‑Fi proxy to your Mac’s LAN IP.

HTTPS MITM

Decrypt selected hosts on Mac; auto-decrypt mobile traffic when enabled.

Dev tools

Map Local, Map Remote, rewrite rules, throttling, HAR export, and session diff.

Install

  1. Download the DMG and open it.
  2. Drag ShubhranshProxy into Applications.
  3. If macOS blocks the app, open System Settings → Privacy & Security and click Open Anyway.
  4. Launch ShubhranshProxy → click Start.
xattr -cr /Applications/ShubhranshProxy.app

Run the command above in Terminal if the downloaded app still won’t open.

For a smooth public download experience, sign and notarize the app with an Apple Developer account before uploading.
