Features

Everything useful, one proxy away

From Mac and mobile capture to SSL decryption, Map Local, breakpoints, throttling, and HAR export — built natively for macOS.

Capture Mac traffic instantly

Start the proxy and route macOS apps through your local listener automatically — no manual per-app setup.

  • System proxy on 127.0.0.1:8888
  • Live session table with method, status, and timing
  • Restore proxy settings when you stop or quit

iPhone & Android on the same Wi‑Fi

Listen on all interfaces and capture mobile device traffic with a root CA and Wi‑Fi proxy setup.

  • Listen on 0.0.0.0:8888
  • AirDrop or export the root certificate
  • LAN IP shown in-app for proxy configuration
